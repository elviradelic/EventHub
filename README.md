# EventHub

EventHub is a console-based Event Booking System developed in C# and .NET.

The project focuses on clean Object-Oriented Programming design, maintainability, extensibility, SOLID principles, and justified use of software design patterns.

## Current Status

The project structure and development environment have been initialized.

## Solution Structure

- `EventHub.Domain` – domain entities, business rules, enumerations, and exceptions
- `EventHub.Application` – application services, use cases, and abstractions
- `EventHub.Infrastructure` – in-memory repositories, factories, and pricing strategies
- `EventHub.Presentation` – console-based user interface
- `EventHub.Tests` – automated unit tests

## Technologies

- C#
